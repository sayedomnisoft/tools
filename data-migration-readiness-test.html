Data migration readiness test: 12 questions before you move

For finance and operations heads about to move products, recipes, customers and balances onto a new system. Twelve questions, three minutes, and the gaps to close before any load.

The short answer

Every order, delivery and invoice copies from your master data, so a list that is wrong when it moves is wrong on every document after go-live. Master data first, software second.

Ready means: you know how many products you have, each has one code, units and recipes are checked, each list has an owner, balances agree to the books, and the first load goes into a test copy.

By Sayed Rashid, ex-auditor, 38 systems taken live. Seven-plus years putting Singapore and regional firms onto one system, and rescuing projects that stalled.

The order of a migration

Count and cleanFirst
  • Active products, customers, suppliers and recipes counted.
  • One code each, duplicates merged, units agreed.

Done when: counts known, duplicates gone

OwnersSecond
  • Each list has a named owner who uses it daily.

Done when: each list signed off

Test loadThird
  • Load into a copy, check, fix the source, load again.

Done when: the copy agrees with the source

BalancesFourth
  • Stock, receivables, payables and bank tied to the trial balance at cut-over.

Done when: finance signs the opening balances

Real loadLast
  • Only when the test copy agrees.

Done when: go-live on the agreed date

Questions

What is the first step in ERP data migration?

Count and clean the master data: products, customers, suppliers and recipes, one code each, units agreed, each list owned and signed off. Master data first, software second.

How much history should we migrate to a new ERP?

Usually open items and balances only: open orders, unpaid invoices, stock on hand and the opening trial balance. Keep older history readable in the old system or an export. Moving every year multiplies the cleaning.

What is a test load in data migration?

Loading the cleaned lists into a copy of the new system first, checking them there, fixing the source file and loading again, before anything goes into the live system.

How do opening balances work in a migration?

At the cut-over date, stock, receivables, payables and bank are loaded as opening balances and must agree to the trial balance of the old books. Finance should sign that they agree.
