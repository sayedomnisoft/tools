How to import one

  1. Open n8n (Cloud trial or your own server) and create a new workflow.
  2. Menu → Import from File and pick the download, or Import from URL and paste the file's link.
  3. Fill in the Settings step first: your company, emails and payment details.
  4. Connect each app where n8n asks for a credential, run the test in the setup guide, then publish.
